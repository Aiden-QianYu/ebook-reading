# ebook-reading

在 macOS Apple 图书中代读电子书，并把可回查的内容摘要保存到 Obsidian。

## 使用

```text
$ebook-reading 阅读《书名》第 3–5 章并生成摘要。
$ebook-reading 继续《书名》，往后读两章。
$ebook-reading 继续《书名》。
```

明确指定章节优先；“往后读两章”从断点续读，未读完的当前章计为第一章。未指定章节时默认按个人阅读 30 分钟的内容量处理。中文初始 400 字/分钟，英文 200 词/分钟，可修改。

章节以真实目录为准，支持 EPUB 3 nav、EPUB 2 NCX、跨文件章节与同一文件中的多个章节。目录缺失或层级有歧义时，需要核对正文。

## 笔记格式

文件命名：`时间-书名-起始章节名称.md`，时间格式为 `YYYY-MM-DD_HH-MM-SS`，同秒重名时增加微秒。

开头先写章节范围，再给出本次最后一句原文。主体包含概括、核心内容、精句、分析、应用建议与回忆问题。进度、估算阅读量、下次接续和技术定位全部放在文末折叠区；不在文首放 YAML 属性。

精句必须匹配本次正文。同一段重试不会重复生成笔记，独立 AI 游标不回退。默认不把 AI 代读写成用户已经读完，也不修改 Apple 图书进度。

## 本机安装与配置

需要 macOS、Apple 图书、Obsidian，以及可读的本地 EPUB。脚本使用 Python 3.9 或更高版本的标准库。

将完整的 `ebook-reading` 文件夹放入个人技能目录，例如 `~/.codex/skills/ebook-reading`。需要当前用户发现目录的环境，可在 `~/.agents/skills/ebook-reading` 建立指向它的链接。已有同名技能时先保留旧版本，再更新。

复制 `config.local.example.json` 为 `config.local.json`，填入实际 Obsidian 仓库绝对路径。`config.json` 保留公共默认参数；保存脚本合并同目录本地配置。这个仓库没有个人仓库路径、书籍正文、实际读书笔记或阅读状态。

`.gitignore` 忽略本地配置、读书状态、电子书和临时文件。没有仓库路径时技能会询问一次。模型/应用提供的本地文件和界面权限决定实际可读写范围，技能本身不能授予权限。

## 验证

在技能目录运行：

```bash
python3 -m unittest discover -s tests -v
```

测试使用虚构 EPUB 和临时 Obsidian 目录，不依赖真实书库。覆盖章节边界、相对续读、非连续章节、时间预算、引用核验、文件命名/排版、去重、状态冲突、来源变化、路径范围和保存恢复。

## 限制

Books 的本地数据库是内部 schema，macOS 更新后可能需要适配。首次相对/时间续读要核对真实起点；绝对章节请求直接从目录起点读取。受保护内容和依赖图片/公式的页面需要正常阅读界面或可用视觉工具；本地 EPUB helper 不解密受保护内容，也不执行 PDF OCR。

PDF 可用模型当前可用的 PDF 工具处理，并按相同摘要/保存规则组织；没有可用工具时需要可读取片段。界面及 PDF 路径不能视为已由本仓库的 EPUB 测试覆盖。
