# 读后整理的选择标准

目标是形成能回查、能理解、能提问、能应用的笔记。以下结构是结合资料后的设计建议，并不是某篇研究验证过的唯一标准。

## 每次默认内容

| 内容 | 写法与作用 |
| --- | --- |
| 开头定位 | 首行说明本次从第几章至第几章及章节名称；紧接着带出本次末尾原文。章中续读或章末未完需标明，非连续章节逐项列出。 |
| 一句话概括 | 回答本段主要解决什么问题，避免空泛的书评式称赞。 |
| 核心内容 | 非虚构通常 3–5 个观点，说明主张、依据/例子、概念关系和适用条件；内容较少时减少条数。 |
| 精句 | 通常 0–3 条简短原文，每条附精确定位和为何选它；不要为了填满数量摘录。 |
| 分析与疑问 | 区分原文与 AI 判断，指出尚缺依据、隐含前提、反例或需要后文解答的问题。 |
| 应用建议 | 与本段有实际联系的 1–2 个小行动，写成“场景—动作—观察指标”；没有合适应用就删掉。 |
| 主动回忆 | 通常 3 个具体问题，折叠参考答案；用户先尝试回答再看答案。AI 生成问题不等于用户已完成回忆练习。 |
| 文末阅读记录 | 日期、Books 进度快照、估算阅读量、来源质量、独立 AI 续读位置与技术属性，全部放在文末折叠区。可写建议复习日期，不设自动提醒。 |

默认正文约 800–1400 中文字，内容很短则缩短；多章或复杂理论可以更长。先读两章不能只概括第一章；按实际章节分组阐述，再写跨章联系。精句少量精选，覆盖范围和关键限定不能为压缩而丢失。

开头固定为阅读范围、最后一句原文，随后进入内容。`assets/session-note.md` 只用于摘要主体，不写进度前言，也不放 YAML frontmatter。进度、用时、模式、下次断点与机器字段由保存脚本追加到文末。原文最后一句来自实际覆盖片段，不使用模型记忆；句中截止就标“本次末尾原文”，不补成完整句子。

## 按类型调整

- **方法/商业/科普**：问题 → 观点 → 证据/案例 → 限定 → 可检验应用。作者举例不自动等于普遍有效的因果证据。
- **理论/哲学**：术语定义、论证链、前提、可能反驳。保留细微区分，不强行提炼成行动鸡汤。
- **历史/传记**：人物、时间、事件、原因/影响、作者视角；区分原始材料与作者解释。
- **小说/文学**：本段情节、人物变化、意象/语言、主题线索与开放问题。只涉及已处理内容，不套用商业行动模板。

## 引文文件

`quotes.json` 为数组；每项包含 `text`、`member`、`start_offset`，可选 `reason`。`start_offset` 是精句首字符在该 session 原始 segment 规范正文中的绝对偏移；保存脚本检查文字在这个位置逐字一致。示意结构（实际值来自正文）：

```json
[{"text": "从本次正文逐字复制的短句", "member": "chapter.xhtml", "start_offset": 123, "reason": "为何这句话值得保留"}]
```

避免省略号拼接不同段落造成虚假原句。OCR 结果有疑点时不用作逐字精句，或明确给出未校验标记且不放入精句区。

## 方法依据

- [Cornell Learning Strategies Center：Cornell Note-taking System](https://lsc.cornell.edu/notes.html)：提供问题、用自己的话复述、反思和复习的步骤。这里借用其学习动作，不要求照搬课堂笔记版式。
- [Karpicke & Blunt，Science，2011，作者发布的论文](https://learninglab.psych.purdue.edu/downloads/2011/2011_Karpicke_Blunt_Science.pdf)，DOI 10.1126/science.1199327：在该研究的科学文本学习任务中，提取练习优于研究中比较的精细学习/概念图条件，并覆盖理解和推断题。支持增加主动回忆问题，不能推广成“AI 代读保证记住”。

上面的定位、引用核验、类型适配和应用建议属于本技能的设计选择。阅读速度默认值是工程起始参数，不是这些资料的研究结论。
